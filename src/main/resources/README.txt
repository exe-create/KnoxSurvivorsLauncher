Drop your launcher artwork here as:

  background.png  (preferred, lossless)
  or background.jpg

Use the full-quality 16:9 export (1920x1080 or 2560x1440 ideal).
The Java launcher paints it cover-fit with bicubic filtering so it
stays sharp and never stretched. If no file is present the launcher
falls back to the solid dark background.

Build scripts copy this folder into the JAR automatically.
You can also drop background.png next to KnoxSurvivorsLauncher.jar
to override without rebuilding.
